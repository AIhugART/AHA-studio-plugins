# AHA Studio plugins for Adobe apps

Manual downloads of the AHA Studio panels for Adobe apps. Each release holds one zip; unzip it to get the plugin file.

| Plugin | Adobe app | File inside the zip | How to install |
|---|---|---|---|
| AHA Paint | Photoshop | `AHA-Paint_PS.ccx` | Double-click the `.ccx` (Adobe Creative Cloud installs it) |
| AHA Clip | Premiere Pro | `AHA-Clip_PR.ccx` | Double-click the `.ccx` |
| AHA Draw | Illustrator | `AHA-Draw_AI.zxp` | Install from AHA Studio ▸ System ▸ Plugins |

Easiest path: install **AHA Studio** first, then use **AHA Studio ▸ System ▸ Plugins** — it installs and updates the plugins for you.

Download page and instructions: https://ahastudio.xyz/download#plugins

Releases are tagged per plugin: `paint-v<version>`, `clip-v<version>`, `draw-v<version>`.
